## Assignment 1 – Overview

This assignment focuses on practising fundamental TypeScript concepts through 8 practical coding problems and writing 2 technical blogs.

### Topics Covered
- Functions, optional parameters and return types.
- Union types and type narrowing.
- Tuples and readonly modifiers.
- Generics, keyof and rest parameters.
- Interfaces and array methods.
- OOP: Classes, inheritance and access modifiers.
- Asynchronous programming: Promises, async/await and error handling.

### Learning Objectives
- Understand core TypeScript concepts.
- Write reusable and type-safe code.
- Improve problem-solving skills through practical exercises.
- Develop technical writing skills by creating two blogs.
